# Gallery

Drop photos in this folder and push. The Gallery page updates itself within a minute or two.

- All common photo types work: JPG, JPEG, PNG, WebP, GIF, AVIF, BMP, TIFF and SVG, in small or capital letters (.jpg or .JPG).
- iPhone HEIC photos usually cannot be converted here. If one does not appear, open the Actions tab to see the message, and send it as JPG instead.
- Photos are resized automatically for the website, so you can upload them straight from your phone.
- The caption comes from the file name: `cold-room-bhuj.jpg` shows as "Cold room bhuj".
- Numbers at the start control the order and are hidden from the caption: `01-front-view.jpg`, `02-inside.jpg`.
- Sub-folders become filter buttons: `gallery/Cold rooms/` and `gallery/Compressors/` give "Cold rooms" and "Compressors" buttons above the photos.
- To remove a photo, delete the file. This folder itself is not published, only the resized copies are.
