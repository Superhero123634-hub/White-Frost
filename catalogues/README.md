# Catalogues

Drop PDF files in this folder and push. The Products page updates itself within a minute or two.

- PDF, Excel (.xlsx/.xls) and Word (.docx/.doc) files are listed. Other files are ignored.
- The page title comes from the file name: `copeland-scroll-compressors_2026.pdf` shows as "Copeland scroll compressors 2026".
- Put files in a sub-folder to group them: `catalogues/Compressors/...` shows under a "Compressors" heading.
- To replace a catalogue, upload a file with the same name. To remove one, delete the file.
- Keep each file under 100 MB (GitHub's limit); compressed PDFs under 20 MB load best on phones.
